# 08. 학습 유형(수강/시험) 확장 설계 방향

> **상태**: Phase 7.0(축 설계 방향 확정) 완료. Phase 7.1(수강 전체 설계), Phase 7.2
> (시험 전체 설계)는 다음 세션에서 진행 예정.
> **스코프 안내**: `04`, `05`, `06`, `07`은 전부 학습 유형 "**과제(Assignment)**"
> 전용 문서다. 이 문서(`08`)부터는 과제 외 학습 유형(수강, 시험 대비)을 다룬다.

## 1. 왜 새 축이 필요한가

`02`에서 정의한 산출물 유형(A.텍스트/B.코드/C.수리/D.디자인) 축은 "학생이 무언가를
만들어 제출하는 과정"을 전제로 한다. 그런데 수강 중 AI 활용(강의 이해 보조)이나 시험
대비 AI 활용(암기·문제풀이 보조)은 **제출할 결과물이 없다** — 목표가 '산출물 완성'이
아니라 '지식의 내재화' 자체이기 때문이다. 따라서 A/B/C/D 축을 그대로 적용할 수 없고,
새로운 최상위 축이 필요하다.

## 2. 축 구조 재정의

```
학습 유형 (최상위, 신규)
 ├─ 과제 (Assignment)        → 기존 산출물 유형(A/B/C/D) 축 그대로 적용 (04~07)
 ├─ 수강 (Course Engagement) → 산출물 유형 구분 없음, 전공 무관 공통 프로세스 (08-1, 예정)
 └─ 시험 대비 (Exam Prep)    → 산출물 유형 구분 없음, 전공 무관 공통 프로세스 (08-2, 예정)
```

**설계 원칙**: 수강·시험은 전공별로 세부 맥락(예시 과목)은 다르지만, 학습 프로세스
자체의 구조는 전공에 무관하게 공통이라고 본다 — 전공은 "축"이 아니라 "맥락 예시"로만
사용해 조합 폭발(학습유형 × 산출물유형 × 전공)을 피한다. 이는 `02`에서 산출물 유형을
상위 축으로 채택해 전공별 매트릭스 재작업 부담을 줄인 것과 같은 논리를 한 단계 더
적용한 것이다.

## 3. 수강(Course Engagement) 학습 프로세스 초안 (5단계)

| 단계 | 이름 | 설명 |
|---|---|---|
| 1 | 예습 | 수업 전 자료(교재/슬라이드)를 미리 살펴보는 단계 |
| 2 | 수업 중 청취·필기 | 강의 내용을 실시간으로 듣고 기록하는 단계 |
| 3 | 실시간 이해 확인 및 질의 | 이해가 안 되는 부분을 그 자리에서 확인·질문하는 단계 |
| 4 | 복습 및 개념 정리 | 수업 후 필기를 바탕으로 개념을 재구성·정리하는 단계 |
| 5 | 자기 점검 | 정리한 내용을 스스로 설명·인출할 수 있는지 확인하는 단계 |

`04`의 5단계 Y축(Bloom 매트릭스용) 구조와 동일한 폭으로 맞춰, 추후 진단 문항 설계 시
Phase 5의 "Q1~Q5=학습단계 1:1 대응" 규칙을 그대로 재사용할 수 있게 했다.

## 4. 시험 대비(Exam Prep) 학습 프로세스 초안 (5단계)

| 단계 | 이름 | 설명 |
|---|---|---|
| 1 | 범위 파악 및 기출 분석 | 시험 범위를 확인하고 기출 유형을 파악하는 단계 |
| 2 | 개념 정리·요약 | 배운 내용을 시험 대비용으로 압축·재구성하는 단계 |
| 3 | 모의 문제 풀이 | 스스로(혹은 AI가 만든) 문제를 풀어보는 단계 |
| 4 | 오답 분석 | 틀린 문제의 원인을 파악하고 보완하는 단계 |
| 5 | 최종 점검 및 실전 시뮬레이션 | 시험 직전 컨디션·시간 배분을 점검하는 단계 |

## 5. AI 개입 깊이(Level) 재해석

`05`의 Level 1(단순보조)/Level 2(부분증강)/Level 3(전면대체) 구분은 원래 "결과물 대체
정도"를 기준으로 했다. 수강·시험은 결과물이 없으므로 기준을 "**이해/기억 과정의 대체
정도**"로 재해석한다.

| Level | 과제(기존) 기준 | 수강·시험(신규) 기준 |
|---|---|---|
| 1. 단순보조 | 정보 검색·문법 교정 | 용어 뜻 검색, 사실 확인 |
| 2. 부분증강 | 구조·아이디어 제시 | 개념 설명 요청, 요약·예시 생성 요청 |
| 3. 전면대체 | 결과물 전체 생성 | AI가 만든 요약본/정리노트/예상문제를 **스스로 재구성하는 과정 없이** 그대로 암기·풀이 — "이해의 외주화" |

## 6. 핵심 위험 가설 (다음 세션 핫스팟 매핑의 출발점)

- **수강**: "AI 실시간 요약본으로 필기를 대체" → 정보는 습득했으나, 손으로 쓰거나 스스로
  재구성하며 겪는 능동적 부호화(active encoding) 과정이 생략되어 장기기억으로 전환되지
  않을 위험
- **시험**: "AI가 만든 예상문제·요약노트만 반복 풀이" → 스스로 문제를 구성해보는 경험이
  없어, 실제 시험에서 기출과 다른 변형 문제에 대한 대응력이 저하될 위험

두 가설 모두 다음 세션(Phase 7.1/7.2)에서 `05`와 같은 형식의 정식 핫스팟 매핑 표로
발전시켜야 한다.

## 7. 기존 문서와의 관계 정리 (액션 아이템)

`02`, `03`, `04`, `05`, `06`, `07`은 실질적으로 전부 "과제" 학습유형 전용 문서였으나,
지금까지는 이를 명시하지 않았다. 다음 세션에서 각 문서 상단에 스코프 안내
(`> 본 문서는 학습 유형 '과제(Assignment)'에 한정된 설계다`)를 추가하는 작업을
Phase 7.1 착수 전 선행 작업으로 남겨둔다.

## 8. 다음 단계 제안

- **Phase 7.1**: 수강(Course Engagement) 전체 설계 — 정식 핫스팟 매핑 → Bloom류
  인지 매트릭스(창조 열의 의미를 '요약 재구성'·'자기설명'으로 재정의 필요) → 학습
  이벤트 명세 → 진단 문항
- **Phase 7.2**: 시험 대비(Exam Prep) 전체 설계 — 동일한 흐름

  각각 만들 필요가 없다**(공통 프로세스이므로) — 이 부분이 Phase 3 때보다 공수가 줄어드는
  지점이 될 것으로 예상
