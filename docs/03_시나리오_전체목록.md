# 03. 시나리오 전체 목록

산출물 유형(A/B/C/D)별 대표 시나리오. 각 시나리오는 페르소나 → 과제 목표 → 학습 목표
→ 학습 프로세스(Timeline) 순으로 구성.

---

## 시나리오 1. 교양 과목 [유형 A: 텍스트/논증형]

- **과목 예시**: 현대 사회와 윤리 — 특정 도서 기반 에세이 작성 및 팀 발표
- **페르소나**: 전공 지식은 풍부하지만 철학적/윤리적 텍스트 읽기와 긴 글쓰기에는 다소
  부담을 느끼는 3~4학년 대학생
- **과제 목표**: 지정 도서를 읽고 자신의 윤리적 관점을 담은 에세이 작성 → 조원들과 의견
  통합하여 최종 발표
- **학습 목표**: 인지적 확장 (텍스트 이해 → 비판적 사고 → 타인과의 의견 조율)

**학습 프로세스**
1. 텍스트 섭취 및 이해 (개인)
2. 관점 설정 및 에세이 초안 작성 (개인)
3. 팀 토론 및 논리 통합 (팀)
4. 시각화 및 발표 준비 (팀)

---

## 시나리오 2. 전공 과목 — CS [유형 B: 코드/구현형]

- **과목 예시**: 컴퓨터 그래픽스 — C++/OpenGL 기반 레이트레이서(Raytracer) 구현 및
  기술 보고서 작성
- **페르소나**: 기본적인 프로그래밍 역량은 갖췄으나, 복잡한 수학적 원리가 결합된 렌더링
  파이프라인/셰이더 프로그래밍에는 낯선 3~4학년 소프트웨어 전공 학부생
- **과제 목표**: 프래그먼트 셰이더로 구를 렌더링하고 빛의 반사 한계를 계산하는 GPU 기반
  레이트레이서 구현 → 트러블슈팅 과정 포함 기술 보고서 제출
- **학습 목표**: 심화 기술의 이해 (컴퓨터 과학 → 컴퓨터 그래픽스)

**학습 프로세스**
1. 요구사항 분석 및 수리적/논리적 이해
2. 아키텍처 설계 및 초기 코드(초안) 작성
3. 디버깅 및 최적화
4. 결과 분석 및 기술 보고서 작성

> 5단계 세분화 버전(CogniTrieve 구현 기준): 요구사항 분석 → 시스템 설계 → 코드 구현 →
> 디버깅 및 테스트 → 보고서 및 회고

## 시나리오 3. 자연과학/공학 계열 [유형 C: 수리/문제해결형] — 신규

- **과목 예시**: 일반물리학, 공업수학 등 전공 기초 수리 과목
- **주제**: 일반물리학 - 전자기학 문제 세트 풀이 및 풀이과정 서술
- **페르소나**: 개념 이해는 어느 정도 되어 있으나, 다단계 수식 전개와 문제 조건을
  수학적으로 번역(formulate)하는 과정에서 막히는 2~3학년 이공계 학부생
- **과제 목표**: 물리 문제 세트(5~7문항)를 풀고, 풀이 과정을 단계별로 서술하여 제출
- **학습 목표**: 개념 이해 → 수식화(formulation) → 계산 → 검증

**학습 프로세스**
1. 문제 조건 파악 및 관련 개념 상기 (개인)
2. 수식화 — 물리 현상을 수학적 모델로 번역 (개인)
3. 계산 및 풀이 전개 (개인)
4. 답 검증 및 풀이과정 서술 (개인)

> 특이점: 코딩의 '디버깅'에 대응하는 지점이 '수식화'와 '답 검증' 두 곳으로 분산됨.
> 코드는 실행 시 즉각 에러가 나지만, 수리 문제는 오답이어도 스스로 알아채지 못하고
> 넘어갈 위험이 있음.

## 시나리오 4. 예체능/디자인 계열 [유형 D: 창작/디자인형] — 신규

- **과목 예시**: 시각디자인 기초, 산업디자인 스튜디오
- **주제**: 브랜드 아이덴티티 디자인 — 컨셉 기획 및 시안 제작
- **페르소나**: 툴 사용 능력은 있으나, 초기 컨셉/아이디어 발상 단계에서 막막함을 느끼는
  2~3학년 디자인 전공 학부생
- **과제 목표**: 가상 브랜드의 아이덴티티(로고, 컬러, 무드보드)를 기획하고 디자인 시안과
  기획 의도서를 제출
- **학습 목표**: 발산적 사고(아이디어 확산) → 컨셉 수렴 → 시각화 → 논리적 정당화

**학습 프로세스**
1. 리서치 및 레퍼런스 수집 (개인)
2. 컨셉/아이디어 발상 (개인) — 최대 위험 핫스팟 후보
3. 시안 제작 및 시각화 (개인, AI 이미지 생성 개입 지점)
4. 기획 의도 서술 및 피드백 반영 (개인/팀)

> 특이점: 코딩·글쓰기는 '논리 전개'가 핵심이지만, 디자인은 **발산적 사고(divergent
> thinking)**가 핵심 → AI 개입의 위험성 정의 자체가 다른 시나리오와 성격이 다름.
