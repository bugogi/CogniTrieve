# 08-1. 수강(Course Engagement) 학습 유형 전체 설계

> **상태**: Phase 7.1 완료. `08`에서 정의한 축 구조·5단계 프로세스를 기반으로
> 핫스팟 매핑 → 인지 매트릭스 → 학습 이벤트 → 진단 문항까지 확정.
> **스코프**: 전공/산출물 유형과 무관한 공통 설계 (`08` 2절 원칙에 따름).

## 1. AI 개입 깊이 매핑 및 핫스팟 (`05` 형식 계승)

| 단계 | Level 1(단순보조) | Level 2(부분증강) | Level 3(전면대체) | 위험도 |
|---|---|---|---|---|
| 1. 예습 | 모르는 용어 검색 | 예습 자료 중 어려운 개념 미리 설명 요청 | 예습 자료 전체를 AI 요약본으로 대체("교재 안 읽어도 됨") | [위험] |
| 2. 수업 중 청취·필기 | 실시간 맞춤법 교정 | 강의 음성을 요약 노트로 자동 변환 요청 | AI 실시간 전사·요약본을 그대로 필기로 채택, 직접 손으로/타이핑으로 기록하지 않음 | **[최고위험]** |
| 3. 실시간 이해 확인 및 질의 | 모르는 용어 즉석 검색 | "이 개념을 다르게 설명해줘" 요청 | 이해 안 되는 부분을 교수·동료에게 묻지 않고 AI에게만 묻고 즉시 다음으로 넘어감(전공 지식체계와의 통합 기회 상실) | [위험] |
| 4. 복습 및 개념 정리 | 필기 오탈자 정리 | 개념 간 관계도(마인드맵) 생성 요청 | "이 단원 요약해줘"로 정리노트 전체를 AI가 생성, 직접 정리 과정 생략 | **[최고위험]** |
| 5. 자기 점검 | 이해도 확인용 단답 퀴즈 생성 요청 | 취약 개념 재설명 요청 | AI의 "잘 이해하셨네요" 같은 반응을 실제 이해의 증거로 착각(직접 인출 시도 없이 안심) | [위험] |

**최고위험 2곳**: 2단계(필기)와 4단계(복습 정리) — 둘 다 "정보를 내 손과 머리를 거쳐
재구성하는 과정" 자체가 통째로 생략된다는 공통점이 있다. `08`의 핵심 위험 가설과
정확히 일치.

## 2. 인지 매트릭스 (Bloom류 재해석)

수강은 '산출물 창조'가 목표가 아니라 '지식의 내재화'가 목표이므로, X축 최상위 단계를
Bloom 원본의 '창조'에서 **"재구성(자신의 언어로 완전히 설명 가능한 상태)"**으로
재해석한다.

```
기억 및 정보 수용 (Remembering & Receiving)
→ 이해 및 의미 부호화 (Understanding & Encoding)
→ 적용 및 기존 지식 연결 (Applying & Connecting)
→ 분석 및 질의 (Analyzing & Questioning)
→ 평가 및 자기 점검 (Evaluating & Self-checking)
→ 재구성 및 자기 설명 (Creating & Self-explanation)
```

| 수강 학습 과정 \ 인지 계층 | 1.기억&수용 | 2.이해&부호화 | 3.적용&연결 | 4.분석&질의 | 5.평가&자기점검 | 6.재구성&자기설명 |
|---|---|---|---|---|---|---|
| 1. 예습 | 새 용어 목록 확인 | 예습자료 핵심 문장 파악 | 이전 수업 내용과 연결 시도 | 예상 질문 목록화 | - | - |
| 2. 수업 중 청취·필기 | 핵심 키워드 받아적기 | 교수 설명의 논리 흐름 이해 | 필기를 나만의 표현으로 바꿔 적기 | 이해 안 되는 지점 표시 | - | **강의 내용을 내 언어로 요약해 필기 완성** |
| 3. 실시간 이해 확인 및 질의 | 모르는 용어 확인 | 재설명을 듣고 이해 시도 | 질문을 통해 개념 연결 보완 | 질문의 핵심을 정확히 구조화 | 질문 전후 이해도 변화 스스로 판단 | - |
| 4. 복습 및 개념 정리 | 필기 재확인 | 필기 내용의 논리 흐름 재이해 | 다른 단원·과목과 연결 | 헷갈리는 개념 간 차이 분석 | 정리 방식의 효율성 자기평가 | **필기를 나만의 정리노트로 재구성** |
| 5. 자기 점검 | 핵심 용어 재확인 | 정리노트를 다시 읽고 이해 확인 | 배운 개념을 새로운 예시에 적용 | 취약 지점 스스로 진단 | 자기 이해도 최종 평가 | 타인에게 설명 가능한 수준으로 재구성 |

**인사이트**: 최고위험은 2행(청취·필기)과 4행(복습·정리)의 **6.재구성 열** — 둘 다
"내 언어로 바꾸는 과정"이 핵심 학습 기제인데, 이 열이 AI로 완전 대체되면 정보를
받아들이기만 하고 내재화하지 못한 채 다음 단계로 넘어가게 된다.

## 3. 학습 이벤트 명세 (`06` 형식 계승, 3개 연속 이벤트)

### 이벤트 8-1: '실시간 필기 전면 위임'
- **이벤트 ID**: `event_notetaking_full_delegation`
- **유형**: 3. 결과물 생성 (Generation)
- **발생 상황(Trigger)**: 강의 속도가 빠르거나 내용이 복잡해 손으로 따라 적기 어려울 때
- **학생의 행동**: 강의 녹음/실시간 전사를 AI 요약 앱에 넣고, 결과 요약본을 그대로
  필기로 채택 — 본인 언어로 다시 쓰는 과정 없음
- **진단 포인트**:
  - "이 요약본의 문장을 내가 직접 다시 설명하라고 하면 할 수 있는가?"
  - "요약본에 없는, 하지만 내가 필기했다면 남겼을 나만의 메모(의문점, 연결점)가 있는가?"
- **매트릭스 대응**: 2행×6열(재구성&자기설명) — **최고위험**

### 이벤트 8-2: '복습 정리 전면 위임'
- **이벤트 ID**: `event_review_summary_delegation`
- **유형**: 3. 결과물 생성 (Generation)
- **발생 상황(Trigger)**: 시험이나 과제 마감이 임박해 복습할 시간이 부족할 때
- **학생의 행동**: 필기 원본을 AI에 통째로 넣고 "이 단원 요약해줘"라고 요청, 생성된
  정리노트를 그대로 최종 복습 자료로 채택
- **진단 포인트**:
  - "이 정리노트의 각 항목이 왜 중요한지 스스로 설명할 수 있는가?"
  - "AI가 요약하며 빠뜨린 내용 중 실제로 중요했던 것이 있었는가?"
- **매트릭스 대응**: 4행×6열(재구성&자기설명) — **최고위험**

### 이벤트 8-3: '이해도 자가검증 위임'
- **이벤트 ID**: `event_self_check_delegation`
- **유형**: 4. 문제 해결 및 검토 (Troubleshooting) — 결과물이 아니라 '자기 이해 상태'의
  검증을 AI에 위임한다는 점에서 검토형으로 분류
- **발생 상황(Trigger)**: 스스로 얼마나 이해했는지 확신이 없을 때
- **학생의 행동**: AI에게 배운 내용을 설명한 뒤 "내가 맞게 이해한 거야?"라고만 확인,
  AI가 "네, 잘 이해하셨어요"라고 답하면 실제 인출 연습(백지에 써보기 등) 없이 이해를
  완료된 것으로 간주
- **진단 포인트**:
  - "AI의 확인 없이, 스스로 백지에 이 개념을 재현해볼 수 있는가?"
  - "AI가 '맞다'고 한 답변이 실제로 시험이나 적용 상황에서도 맞을지 검증해봤는가?"
- **매트릭스 대응**: 5행×5열(평가&자기점검) — 위험

## 4. 진단 문항 (Phase 5 형식 계승)

`07`의 일반화 규칙(문항 텍스트 분기, 채점 로직 공통) 그대로 적용. Q2·Q4가 핫스팟
문항이라는 점이 CS(유형 B)와 문항 번호까지 동일하게 맞아떨어진다.

```json
{
  "learning_type": "수강 (Course Engagement)",
  "questions": [
    "나는 수업 전 예습 자료를 AI 요약본에만 의존하지 않고 직접 읽어봤다.",
    "나는 수업 중 필기를 AI 자동 요약에 전적으로 의존하지 않고 직접 기록했다.",
    "나는 이해 안 되는 부분을 AI뿐 아니라 교수·동료에게도 질문하려 시도했다.",
    "나는 복습 노트를 AI가 만든 요약본을 그대로 쓰지 않고 스스로 정리했다.",
    "나는 AI의 '잘 이해했다'는 반응이 아니라, 직접 설명해보며 이해도를 확인했다."
  ],
  "hotspot_primary": 2,
  "hotspot_secondary": 4
}
```

**페르소나 판별**: `07`에서 정의한 4개 페르소나(맹목적 의존형/효율 중심형/방어형/
자기 주도형) 명칭과 공식을 그대로 재사용 — 도메인 무관 정의라 수정 불필요. 다만
"결과물"이라는 표현 대신 "이해 상태"로 해석하면 자연스럽다(예: 맹목적 의존형 = "강의
내용의 수용부터 재구성까지 전반을 AI에 위임").

## 5. 과제(Assignment) 축과의 차이 요약

| 비교 항목 | 과제(04~07) | 수강(08-1) |
|---|---|---|
| 산출물 유형 구분 | A/B/C/D 4종 매트릭스 필요 | 불필요 (공통 1종) |
| 최고위험 지점 | 유형별 상이(수식화, 디버깅 등) | 필기(2단계), 복습정리(4단계) — 고정 |
| X축 최상위 단계 | 창조(결과물 완성) | 재구성(자기 언어 설명) |
| 이벤트 수 | 유형별 1~3개 | 3개 (전 학습유형 공통) |
| 2단계(로그분석) 결과물 비교 | 코드/텍스트/수식/이미지별 상이 | 해당 없음 — 필기·정리노트 자체를 "AI 원본 대비 재구성 비율"로 단일 비교 가능 (Phase 6a의 텍스트 유사도 방식 재사용) |

`08` 8절에서 예상한 대로, 산출물 유형별 매트릭스 4종을 만들 필요가 없어 Phase 3보다
공수가 크게 줄었다.
