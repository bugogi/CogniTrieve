# 08-2. 시험 대비(Exam Prep) 학습 유형 전체 설계

> **상태**: Phase 7.2 완료. `08`의 축 구조·5단계 프로세스를 기반으로 `08-1`(수강)과
> 동일한 절차(핫스팟 → 인지 매트릭스 → 학습 이벤트 → 진단 문항)로 설계.
> **스코프**: 전공/산출물 유형과 무관한 공통 설계.

## 1. AI 개입 깊이 매핑 및 핫스팟

| 단계 | Level 1(단순보조) | Level 2(부분증강) | Level 3(전면대체) | 위험도 |
|---|---|---|---|---|
| 1. 범위 파악 및 기출 분석 | 기출문제 검색 | 출제 경향·빈출 유형 요약 요청 | AI가 정리한 "예상 족보"를 그대로 시험 범위로 간주, 원래 범위 확인 생략 | [위험] |
| 2. 개념 정리·요약 | 핵심 용어 재확인 | 개념 설명·요약 생성 요청 | 범위 자료 전체를 AI에게 넣어 요약·암기카드를 통째로 생성, 직접 정리 과정 생략 | [위험] |
| 3. 모의 문제 풀이 | 계산 검산 | 풀이 힌트 요청 | 문제를 AI에게 그대로 주고 최종 답과 풀이를 받아 암기, 스스로 처음부터 풀어보지 않음 | **[최고위험]** |
| 4. 오답 분석 | 정답 확인 | 오답 이유 설명 요청 | "왜 틀렸어?"라고 묻고 설명을 읽기만 함, 같은 유형 문제를 재시도해 실제로 맞힐 수 있는지 검증하지 않음 | **[최고위험]** |
| 5. 최종 점검 및 실전 시뮬레이션 | 시간표·준비물 확인 | 실전 모의고사 문제 생성 요청 | AI가 예상 적중 문제를 준다는 것에 의존해 실전 감각(시간 배분, 긴장 관리) 훈련 자체를 생략 | [위험] |

**최고위험 2곳**: 3단계(모의 문제 풀이)와 4단계(오답 분석) — 인지과학에서 말하는
**인출 연습(retrieval practice)**과 **오류로부터의 재학습(error-based relearning)**이
정확히 이 두 지점에서 일어난다. 이 두 곳을 AI로 대체하면 "풀어봤다/확인했다"는 느낌만
남고 실제 시험 상황에서 재현 가능한 실력으로 이어지지 않는다.

## 2. 인지 매트릭스 (Bloom류 재해석, `08-1`과 동일 X축 재사용)

`08-1`(수강)과 동일한 학습 유형 범주(산출물 없는 내재화 과정)이므로 X축을 그대로
재사용한다: 기억&수용 → 이해&부호화 → 적용&연결 → 분석&질의 → 평가&자기점검 →
재구성&자기설명.

| 시험 대비 학습 과정 \ 인지 계층 | 1.기억&수용 | 2.이해&부호화 | 3.적용&연결 | 4.분석&질의 | 5.평가&자기점검 | 6.재구성&자기설명 |
|---|---|---|---|---|---|---|
| 1. 범위 파악 및 기출 분석 | 기출문제 목록·빈출유형 확인 | 출제 경향이 형성된 배경 이해 | 기출 유형을 공부 계획에 연결 | 부족한 영역·강한 영역 분석 | - | - |
| 2. 개념 정리·요약 | 핵심 공식·용어 재확인 | 개념 간 관계 이해 | 개념을 요약카드·노트로 표현 | 헷갈리는 개념 간 차이 분석 | 정리 방식의 효율성 자기평가 | 나만의 언어로 개념 압축 재구성 |
| 3. 모의 문제 풀이 | 문제 유형별 풀이공식 상기 | 문제 조건이 요구하는 개념 이해 | 배운 개념을 실제 문제에 적용해 풀이 | 풀이 중 막힌 지점 스스로 파악 | 풀이 시간·정확도 자체 평가 | **AI 도움 없이 스스로 문제를 끝까지 풀어내는 인출 훈련 완성** |
| 4. 오답 분석 | 정답 확인 | 오답 이유(개념 오해 vs 실수) 이해 | 올바른 접근법을 유사 문제에 재적용 | 반복되는 실수 패턴 분석 | 오답 대비 실력 향상도 자기평가 | **틀린 이유를 AI 설명 없이 스스로 재구성해 다시 풀어내기(재시도)** |
| 5. 최종 점검 및 실전 시뮬레이션 | 준비물·시간표 확인 | 시험 형식(시간 배분 등) 이해 | 실전과 동일한 조건에서 모의시험 실시 | 시간 부족·긴장 등 실전 변수 분석 | 최종 컨디션·자신감 자기평가 | - |

**인사이트**: 최고위험은 3행·4행의 **6.재구성 열** — 둘 다 "AI 없이 실제로 해내야
증명되는" 지점이라는 공통점이 있다. `08-1`의 최고위험(필기, 복습정리)이 "정보를 내
언어로 바꾸는 과정"이었다면, 시험 대비의 최고위험은 "실전과 동일한 조건에서 스스로
인출해내는 과정"이라는 점에서 성격이 한 단계 더 나아간다 — 단순 재구성을 넘어 **시간
압박·변형 조건 하의 적용력**까지 요구되기 때문이다.

## 3. 학습 이벤트 명세 (전체 프로젝트 이벤트 번호 계승: 9-1~9-3)

### 이벤트 9-1: '모의 문제 풀이 전면 위임'
- **이벤트 ID**: `event_mock_exam_solving_delegation`
- **유형**: 3. 결과물 생성 (Generation)
- **발생 상황(Trigger)**: 시간이 부족하거나 어려운 문제를 마주쳤을 때
- **학생의 행동**: 문제를 AI에게 그대로 주고 최종 답과 풀이를 받아 그대로 암기, 스스로
  처음부터 풀어보는 시도 없이 다음 문제로 넘어감
- **진단 포인트**:
  - "AI 도움 없이 이 문제를 처음부터 다시 풀 수 있는가?"
  - "이 문제와 조건이 살짝 다른 변형 문제도 풀 수 있는가?"
- **매트릭스 대응**: 3행×6열(적용력의 재구성) — **최고위험**

### 이벤트 9-2: '오답 원인 수동적 수용'
- **이벤트 ID**: `event_error_analysis_passive_acceptance`
- **유형**: 4. 문제 해결 및 검토 (Troubleshooting)
- **발생 상황(Trigger)**: 오답을 확인한 뒤 원인을 파악해야 할 때
- **학생의 행동**: AI에게 "왜 틀렸어?"라고 묻고 설명을 읽기만 함, 같은 유형 문제를
  재시도해 실제로 맞힐 수 있는지 검증하지 않고 다음 문제로 넘어감
- **진단 포인트**:
  - "이 오답의 원인을 AI 설명 없이 내 언어로 다시 설명할 수 있는가?"
  - "동일한 실수를 다른 문제에서도 반복하고 있지는 않은가?"
- **매트릭스 대응**: 4행×6열(오답의 재구성) — **최고위험** (CS의
  `event_code_blind_debugging`과 구조적으로 동일한 패턴 — 원인을 읽기만 하고 직접
  재현·재시도하지 않음)

### 이벤트 9-3: '개념 정리 노트 전면 위임'
- **이벤트 ID**: `event_concept_summary_delegation`
- **유형**: 3. 결과물 생성 (Generation)
- **발생 상황(Trigger)**: 시험 범위가 방대해 직접 정리할 시간이 부족할 때
- **학생의 행동**: 전체 범위 자료를 AI에 넣고 "요약·암기카드 만들어줘"라고 요청, 생성된
  자료를 그대로 최종 암기 자료로 채택
- **진단 포인트**:
  - "이 요약카드를 보지 않고 스스로 설명할 수 있는가?"
- **매트릭스 대응**: 2행×6열(개념정리) — 위험 (`08-1`의
  `event_review_summary_delegation`과 유사한 패턴이나, 최고위험 등급인 3·4단계보다는
  한 단계 낮음 — 개념을 몰라도 문제 풀이·오답 분석 단계에서 재차 노출되며 보완될
  여지가 있기 때문)

## 5. 학습 유형 3종 비교 요약

| 비교 항목 | 과제(04~07) | 수강(08-1) | 시험 대비(08-2) |
|---|---|---|---|
| 최고위험 성격 | 산출물별 상이 | 정보의 내 언어 재구성 | 시간 압박 하의 인출·재시도 |
| 최고위험 단계 | 유형별 상이 | 필기(2), 복습정리(4) | 모의풀이(3), 오답분석(4) |
| 이벤트 유형 분포 | 3(생성) 중심, 4/5 일부 | 3(생성) 2개 + 4(검토) 1개 | 3(생성) 2개 + 4(검토) 1개 |
| 진단 핫스팟 문항 | 유형별 상이 | Q2, Q4 | Q3, Q4 |
| 특이사항 | 산출물 유형 4종 매트릭스 필요 | 공통 1종 | 공통 1종, 단 "실전 조건 재현"이라는 추가 축 존재 |

수강과 시험 대비 모두 이벤트 유형 분포가 "생성 2개 + 검토 1개"로 동일한 패턴을 보이는
점이 흥미롭다 — 두 학습 유형 모두 (1) 정보 압축·정리를 AI에 맡기는 두 개의 생성형
위임과, (2) 자기 검증을 AI에 맡기는 한 개의 검토형 위임으로 구성된다는 공통 구조를
갖는다. 사후 합리화(유형 5)에 해당하는 이벤트는 아직 발견되지 않았는데, 이는 수강·
시험 대비 모두 "이미 완성된 결과물을 사후 정당화"할 대상 자체가 없기 때문으로 보인다
(과제처럼 제출용 산출물이 없음).
