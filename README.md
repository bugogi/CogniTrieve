## 핵심 개념

- 생성형 AI가 보편화된 학습 환경에서, 학습자가 자신의 AI 활용 방식을 스스로 인식하고
  성찰하도록 돕는 시스템. AI를 무조건 배척/의존하는 이분법을 넘어, **학습 이벤트** 단위로
  AI 개입의 목적·맥락·기여도를 진단.
- 핵심 이론: 메타인지(Metacognition), 인지적 구두쇠(Cognitive Miser), 바람직한 어려움
  (Desirable Difficulty) / 생산적 마찰(Productive Friction), 블룸의 교육목표 분류(Bloom's
  Revised Taxonomy).
- 3단계 파이프라인: **메타인지 기반 사전 진단 → 사용자 프롬프트 로그 입력(교차검증) →
  학습 확인 질문(전이 검증)**

**Phase 3 비고**: 산출물 유형 축의 공수 절감 효과는 A/B/C/D 4개 유형 최초 구축 시점이
아니라, 향후 기존 4개 유형 중 하나에 속하는 신규 전공이 추가될 때부터 발생함(매트릭스
재사용 가능).

**Phase 6 스코프 결정**: 코드(CogniTrieve) 실제 리팩토링은 포함하지 않고, 설계 문서
(`07`) 갱신까지만 진행하기로 확정.

**Phase 7 비고**: '학습 유형(과제/수강/시험)'을 새로운 최상위 축으로 승격하고, 기존
산출물 유형(A/B/C/D)은 "과제" 학습유형 내부 하위 분류로 재정의함. `04`~`07`은 모두
"과제" 전용 문서였다는 스코프 안내를 다음 세션 착수 전 각 문서에 추가할 예정(액션
아이템, `08` 7절 참조).
